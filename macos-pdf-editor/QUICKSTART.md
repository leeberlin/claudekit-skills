# 🚀 Quick Start Guide

## Build và chạy trong 5 phút

### Bước 1: Cài đặt Xcode
```bash
# Mở App Store, tìm "Xcode" và cài đặt
# Hoặc download từ: https://developer.apple.com/xcode/
```

### Bước 2: Download source code
```bash
cd ~/Desktop
# Download ZIP từ GitHub hoặc clone:
git clone https://github.com/yourusername/macos-pdf-editor.git
cd macos-pdf-editor
```

### Bước 3: Mở và Run
```bash
# Mở project
open PDFEditor.xcodeproj

# Trong Xcode:
# 1. Chọn "My Mac" ở góc trên trái
# 2. Nhấn ⌘ + R
```

### Bước 4: Sử dụng
1. Click **"Open PDF File"**
2. Chọn file PDF
3. Click vào **Text Tool** hoặc các tool khác
4. Bắt đầu chỉnh sửa!

## ⌨️ 10 Shortcuts quan trọng nhất

| Shortcut | Chức năng |
|----------|-----------|
| `⌘ + O` | Mở file PDF |
| `⌘ + S` | Lưu file |
| `⌘ + T` | Text tool |
| `⌘ + D` | Draw tool |
| `⌘ + H` | Highlight tool |
| `⌘ + Z` | Undo |
| `⌘ + Shift + Z` | Redo |
| `⌘ + +` | Zoom in |
| `⌘ + -` | Zoom out |
| `⌘ + F` | Search |

## 🎯 3 Use Cases phổ biến

### 1. Điền form PDF
```
1. Mở PDF
2. Click "Form Fields" ở sidebar
3. Click vào field cần điền
4. Nhập thông tin
5. ⌘ + S để lưu
```

### 2. Đánh dấu và highlight document
```
1. Mở PDF
2. ⌘ + H để chọn Highlight tool
3. Chọn màu từ color picker
4. Drag qua text cần highlight
5. ⌘ + S để lưu
```

### 3. Thêm chú thích (annotations)
```
1. Mở PDF
2. ⌘ + T để chọn Text tool
3. Click vào vị trí cần thêm chú thích
4. Gõ nội dung
5. ⌘ + S để lưu
```
